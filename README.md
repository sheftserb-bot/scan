# Сканер документов (PWA)

Сканер для телефона: ставится на экран как приложение прямо с GitHub Pages, без App Store и без Google Play. Работает на iPhone и Android, после первой загрузки — офлайн.

## Что умеет

- Автопоиск границ листа на фото, ручная подстройка углов с лупой
- Выравнивание перспективы (лист снят под углом — на выходе ровный)
- Удаление теней и выравнивание фона бумаги
- Фильтры: Оригинал, Документ, Цвет+, Серый, Ч/Б
- Поворот, пересъёмка границ, многостраничный PDF (A4, Letter или по размеру фото)
- Распознавание текста (OCR): русский, английский, латышский
- Все данные остаются на телефоне, никуда не отправляются (кроме однократной загрузки языковых данных OCR)

## Размещение на GitHub Pages

1. Создайте на GitHub новый репозиторий (например, `scanner`), публичный.
2. Загрузите в него **содержимое** этой папки (не саму папку): `index.html`, `app.js`, `core.js`, `sw.js`, `style.css`, `manifest.json`, `.nojekyll`, папки `lib/` и `icons/`.
3. Settings → Pages → Source: **Deploy from a branch** → Branch: `main`, папка `/ (root)` → Save.
4. Через 1–2 минуты сайт будет по адресу `https://ИМЯ.github.io/scanner/`.

## Установка на телефон

**iPhone (Safari):** откройте адрес → кнопка «Поделиться» → «На экран “Домой”».
**Android (Chrome):** откройте адрес → меню ⋮ → «Установить приложение» / «Добавить на главный экран».

Первый запуск должен быть с интернетом: скачивается около 13 МБ (движок OpenCV). Дальше всё работает без сети.

## Обновление

При изменении файлов поменяйте номер в `sw.js` (`const CACHE = 'scanner-v2'`), иначе телефон будет показывать старую версию из кэша.

## Из чего сделано

- [OpenCV.js](https://opencv.org) (Apache 2.0) — поиск границ, перспектива, фильтры
- [jsPDF](https://github.com/parallax/jsPDF) (MIT) — сборка PDF
- [Tesseract.js](https://github.com/naptha/tesseract.js) (Apache 2.0) — OCR, подгружается при первом нажатии «Текст»
